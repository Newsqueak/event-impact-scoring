# Event Impact Scoring（事件影响力评分 · v3）

一套**可复现、可审计、可跨事件/跨批次比较**的"事件影响力评分"方法学 + 工具包。给定一批科技/财经重大事件（新闻、发布会、政策、资本动作），按统一规则打分、定级、排名，并**自动产出逐事件独立重算的审计表（§6.1）**。

> 源自一个真实的月度 AI/科技行业重大事件调研方法论（v3 权重 + 两层放大器 + 归一性封顶 + 审计 SOP），固化为可复用资产。

## 为什么这样设计

- **两层模型**：基线层 B（7 维加权，归一到 0–100）承载"常规影响力"；叠加层 F（尾部风险放大器，离散档位 0–15）承载"比 5 分还大"的反常尾部效应（大佬一句话引爆板块、一份禁令砸倒全市场）。总评 `T = min(B + F, 100)` 软封顶。
- **参数一经确定，整批事件共用一套**——保证跨事件、跨批次可比、可审计、可复现。方法论任何参数变更须升版本号（v3→v4）并全量重排。
- **承重数字二核**：S/A 级结论的关键数字须 ≥2 个独立信源交叉验证；单源事件只标"待再核"，不进 S 级结论。

## 快速上手

### 1. 理解打分规则
先读 `references/scoring-rules.md`（评分锚点、触发器判定、算例），再按 `SKILL.md` 的七步 SOP 给每个事件打 7 维分（0–5）并标放大器档位。

7 维权重（v3）：**技术 24% / 影响范围 20% / 战略 17% / 资本 15% / 治理 12% / 全球接纳度 7% / 市场验证 5%**（Σ=100%）。

尾部放大器 F（命中才加，上限 +15）：
- **T1 大佬言论/发布会**（战略维标签）+5~+8
- **T2 资本叙事拐点**（资本维标签）+3~+6
- **T3 政策尾部风险**（治理维标签）+6~+10

定级：S ≥ 85 / A 70–84 / B 60–69 / C < 60。

### 2. 自动生成 §6.1 审计表

把打分结果写进一个 `events.json`（顺序固定为 **技/范/战/资/治/接/验**，对应权重 24/20/17/15/12/7/5）：

```json
{
  "events": [
    { "id": "GPT-6 Astra", "scores": [5,5,4,4,3,4,3], "amplifier": 6, "amp_tags": "T1" },
    { "id": "NVIDIA", "scores": [4,4,5,5,3,3,3], "amplifier": 8, "amp_tags": "T1" }
  ]
}
```

运行：

```bash
python scripts/audit_table.py --input events.json
```

脚本一次产出：
- **§6.1 逐事件审计表**（加权和 Σ、B 精确、B 取整、F、T、是否触发 100 软封顶、定级）
- **按 T 降序的排行榜**
- **一致性校验**（权重和 Σ=100、F≤15、封顶标记、B 精确/取整对照列）

也可用内置 13 事件样例做自检回归：

```bash
python scripts/audit_table.py --demo
```

## 产出报告模板

最终报告按 `assets/sample-report.md` 的结构套写：
§一 评分标准 → §二 排行榜（按 T 降序）→ §三 二核核查表 → §四 主线判断 → §五 局限性 → §六 审计表 + SOP + 未决项。

## 方法论版本与校验机制

- 本包实现**方法论 v3**（7 维权重、T1/T2/T3 触发器档位、软封顶与定级阈值）。
- 若改动权重/触发器/定级阈值等**方法论参数** → 升方法论版本号（v3→v4）并全量重排；仅文档/信源/脚本等**非参数**改动 → 升 skill 包修订号即可。
- 取整用标准四舍五入；数据特性下 Σ/5 只到一位小数（末位 0/2/4/6/8），无 0.5 边界歧义。
