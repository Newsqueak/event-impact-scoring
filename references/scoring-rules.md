# 评分细则（v3）

> 本文件是 event-impact-scoring skill 的评分权威。打分、复核、出审计表前先读它。
> 原则：**参数一旦确定，整批事件共用一套；任何变更升版本号并全量重排。**

## 1. 基线层 B：7 维加权（每维 0–5 分）

| 维度 | 权重 | 含义 | 评分锚点 |
|---|---|---|---|
| 技术突破性 | 24% | 能力/算力的代际跃升 | 5=代际新范式；3=同代优化；1=边缘改进 |
| 影响范围 | 20% | 受影响用户/行业/国家 | 5=全球多行业；3=单行业多国；1=小众 |
| 战略/产业信号 | 17% | 巨头转向、生态卡位、资本流向 | 5=路线级转向；3=战术调整；1=例行 |
| 资本/市场冲击 | 15% | IPO、大额投资、估值跳变 | 5=千亿级/纪录级；3=数十亿；1=象征性 |
| 治理/政策涟漪 | 12% | 监管、国际合作、标准推动 | 5=安理会/多法域；3=单一监管；1=无 |
| 全球接纳度/全社会共识 | 7% | 跨阵营接纳/共识 vs 争议分裂 | 5=广泛共识；3=部分认同；1=高度争议 |
| 市场验证 | 5% | 事件所处**验证周期阶段**（见 §5） | 反映"度与时机"，非"是否已验证" |

- 权重 Σ = 24+20+17+15+12+7+5 = **100%**（定级前必校验）。
- **B = [Σ(维度分 × 权重)] ÷ 5**，全 5 分 = 100、全 0 分 = 0，故 B ∈ [0,100]。
- 数据特性：维度分都是整数，Σ 为整数，Σ÷5 只到一位小数且末位必为 0/2/4/6/8，**不会出现 0.5 边界**，四舍五入无歧义。

## 2. 叠加层 F：尾部风险放大器（离散触发器，命中才加，上限 +15）

**它解决什么**：常规加权有天花板——某维最多 5 分、B 最多 100。当一次尾部事件发生（大佬一句话引爆板块 / 一份禁令砸到全市场），相关维度往往已饱和 5 分，B 表达不出"比 5 分还大"的反常冲击。放大器 F 就是这个**溢出出口（天花板逃逸阀）**，承载超出维度上限的反常尾部效应。

| 触发器 | 归属维度（仅审计标签） | 加分区间 | 判定要点 |
|---|---|---|---|
| **T1 大佬言论/发布会** | 战略维 | +5 ~ +8 | 头部人物（马斯克/奥特曼/黄仁勋/扎克伯格等）公开发言或发布会，引发**可观测的方向背离**市场反应或舆论反常。例：联发科涨停 +9.94% 但 NVIDIA 盘前 -1.34%（方向背离）。 |
| **T2 资本叙事拐点** | 资本维 | +3 ~ +6 | 一级/产业/私募圈态度转变，估值范式切换、老股流通、Pre-IPO 狂欢等叙事新变量。 |
| **T3 政策尾部风险** | 治理维 | +6 ~ +10 | 政治禁令、实体/商业名单、取缔、阻止、封禁等说辞落地或发酵。 |

- **F = 命中的触发器档位相加，F ≤ 15**（硬性上限，防多触发器无限堆叠；多命中须先过 §3 封顶再定级）。
- 档位是**主观离散判断**，非客观公式；跨版本比较必须固定同一档位定义，否则不可比。
- **关键区分（防张冠李戴）**："归属维度"只回答"这个尾部效应**概念上**属于哪一维"，用于叙事与审计追溯，**不参与任何 0–5 维度加权**。命中后 F 作为裸加分**直接加在总评 T 的顶层**，不回头改对应维度的 0–5 分。

## 3. 总评与封顶

- **T = min(B + F, 100)**（软封顶）。把叠加上限锁回 0–100，恢复归一基准，使按 0–100 设计的定级阈值严格自洽。
- 若某事件 B+F 越 100，须记录"已封顶至 100"并保留原始 B+F 留痕。
- **定级：S ≥ 85 / A 70–84 / B 60–69 / C < 60。**

## 4. 等价换算（仅审计核对，不进计算）

`F ÷ 20 = 0–5 维度当量`（如 +8 → 0.40；+15 → 0.75，均落在 0–5 区间）。

速查表（折 0–5 维度当量）：

| F | 折 0–5 维度当量（F÷20） | 说明 |
|---|---|---|
| +3 | 0.15 | T2 下限 |
| +5 | 0.25 | T1 下限 / pacing 共识类 |
| +6 | 0.30 | T2 上限 / T1 中位 |
| +8 | 0.40 | T1 上限 / T3 中位 |
| +10 | 0.50 | T3 上限（政策尾部最高） |
| +15 | 0.75 | 多触发器叠加理论峰值（须先过 §3 封顶再定级） |

**口径澄清（防混淆）**：榜单表"放大器"列是**直接加到 0–100 基线**的叠加分（如 GPT-6 基线 85 + 放大器 +6 = 总评 91），与 `T = min(B+F,100)` 一致，即"放大器 +N 就是加 N 分"。本换算表仅作审计核对，**不改变**榜单表的加法口径。

## 5. "市场验证"维度的度与时机原则

本维度**不是机械衡量"是否已被市场验证"**，而是判断事件当前处于验证周期哪一段：
- **拐点段（影响最大）**：事件爆发扩散初期，伴随"模糊/朦胧感 + 小范围初步市场验证"的消息发酵，形成趋势拐点——此时扩散速度与影响力最大。
- **衰竭段（影响最小）**：一旦**完全**被市场验证（靴子落地），利好利空即出尽，影响力进入衰竭期，只能为下一波类似事件做铺垫、沉淀为社会记忆储备。
- 因此：打分时结合"事件处于验证周期哪个阶段"，**验证滞后于事件影响本身**；"已完全验证"反而对应较低的当期影响力。该维度权重仅 5%，作边际校准。

## 6. 完整算例（GPT-6 Astra）

- 7 维分（技/范/战/资/治/接/验）= 5/5/4/4/3/4/3
  - Σ = 5×24 + 5×20 + 4×17 + 4×15 + 3×12 + 4×7 + 3×5 = 120+100+68+60+36+28+15 = **427**
  - B = 427 ÷ 5 = 85.4 → 取整 **85**
- 命中 **T1**（Brockman"AGI 时代"定调 + DevDay 爆点，战略维标签）→ **F = +6**
- **T = min(85 + 6, 100) = 91**（S 级）
- 那个"+6"直接加在顶层 85 上，**没有回头去改"战略维"的 4 分**——这就是"不参与加权、但参与总分"的准确含义。

## 7. 归一性审核规则（6 条）

1. **权重和归一校验**：7 维权重 Σ=100%，任何版本改动后先校验，否则不可定级。
2. **基线分归一**：B = [Σ(维度分×权重)]÷5，B∈[0,100]。
3. **放大器封顶**：F=T1+T2+T3（命中者相加），F≤15 硬上限。
4. **总评软封顶**：T=min(B+F,100)，定级阈值严格适用。
5. **可复现换算**：`F÷20=0–5 等价分`；审计发现 B+F 越 100 须记录封顶并留痕。
6. **一致性铁律**：整批事件同用一套参数，参数变更须升版本号并全量重排。

## 8. 独立复核 SOP（7 步，供每版本复用）

1. **先校权重、再定级**：权重 Σ=100%，否则停。
2. **独立重算**：B 由维度分独立加权，不沿用旧值；逐事件填审计表。
3. **放大器留痕**：每个触发器写清"触发事件 + 归属维度标签 + 加分"，F 求和校验 ≤15。
4. **封顶校验**：对每个事件算 B+F，>100 记"已封顶"并保留原始 B+F。
5. **铁律一致性**：整批同参，变更必须升版本全量重排。
6. **承重数字二核**：每条 S/A 级承重数字须 ≥2 独立信源；单源标"待再核"，不进 S 级结论。
7. **变更留痕**：本机制自 v3 起生效；关键审核发现须记录并说明修复方式与对现值的影响。

## 9. 已知未决项（跨版本须知）

- 触发器 F 档位（+5~+8 等）为**主观离散判断**，跨版本比较须固定同一档位定义。
- "市场验证"5% 已降级为边际项，"度与时机"原则仍需结合验证周期手动判断——这是该维度无法纯公式化的根因，留待引入"验证周期阶段"子标签后量化。
