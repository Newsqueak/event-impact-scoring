## 一、影响力评估标准（v3 · 7 维基线 + 尾部风险放大器）

### 1.1 基线评分（7 维加权，每维 0–5，权重合计 100%）

| 技术突破性         | **24%** | 能力/算力的代际跃升              | 5=代际新范式；3=同代优化；1=边缘改进 |
| 影响范围          | 20%     | 受影响用户/行业/国家             | 5=全球多行业；3=单行业多国；1=小众  |
| 战略/产业信号       | **17%** | 巨头转向、生态卡位、资本流向          | 5=路线级转向；3=战术调整；1=例行   |
| 资本/市场冲击       | **15%** | IPO、大额投资、估值跳变           | 5=千亿级/纪录级；3=数十亿；1=象征性 |
| 治理/政策涟漪       | 12%     | 监管、国际合作、标准推动            | 5=安理会/多法域；3=单一监管；1=无  |

| 市场验证          | **5%**  | 事件所处**验证周期的阶段**（见 §1.3） | 反映"度与时机"，非"是否已验证"     |

**基线百分制 = [Σ(维度分 × 权重)] ÷ 5**（全 5 分 = 100，全 0 分 = 0）。

### 1.2 尾部风险放大器（独立叠加层 · 离散触发器 · 上限 +15）

**它解决什么**：常规加权有天花板——某维度最多 5 分，加权后 B 最多 100。当一次**尾部事件**发生（大佬一句话引爆整个板块 / 一份禁令砸到全市场），相关维度往往**早被打到 5 分饱和**，常规 B 表达不出"比 5 分还大"的反常冲击。放大器 F 就是那个**溢出出口（天花板逃逸阀）**，专门承载"超出维度上限"的反常尾部效应。

**两层结构（关键）**：

1. **基线层 B** = 7 维加权，归一化到 0–100。
2. **叠加层 F** = 触发器离散档位分相加（0–15）。
3. **总评 T = min(B + F, 100)**。F 作为**顶层加项**加在 B 之上，**不写回任何维度的 0–5 分、不重新走 7 维权重**。

| 触发器                                                                    | 归属维度* | 加分区间     | 标记     |
| ---------------------------------------------------------------------- | ----- | -------- | ------ |
| **T1 大佬言论/发布会**：马斯克、奥特曼、黄仁勋、扎克伯格等头部人物公开发言/发布会，引发可观测的**方向背离**市场或舆论反常反应  | 战略维   | +5 ~ +8  | 反常市场效应 |
| **T2 资本叙事拐点**：一级市场、全球产业资本圈、私募圈态度转变 / 普遍叙事出现新变量（老股流通、Pre-IPO 狂欢、估值范式切换） | 资本维   | +3 ~ +6  | 叙事拐点   |
| **T3 政策尾部风险**：政治政策禁令、被列商业名单（实体/黑名单）、取缔、阻止、封禁等说辞                        | 治理维   | +6 ~ +10 | 政策尾部风险 |

\* **"归属维度"是标签，不是计算路径**：它只回答"这个尾部效应**概念上**属于哪个维度"，用于叙事与审计追溯；**不参与任何 0–5 维度分的加权**。命中后 F 作为裸加分**直接加在总分 T 的顶层**（见下方算例）。这样区分是为了避免误读为"放大器改了对应维度的分数"。

**怎么加、怎么用（离散档位，非连续公式）**：触发器**不是算出来的**，而是"出现了某类可观测事件"就**归档给分**；命中的相加得 F，再用 `T = min(B+F,100)` 出总评。

**算例（GPT-6 Astra）**：

- 7 维分（技/范/战/资/治/接/验）= 5/5/4/4/3/4/3 → 加权和 Σ=4.27/5 → **B=85**
- 命中 **T1**（Brockman"AGI 时代"定调 + 9/29 DevDay 爆点，战略维标签）→ **F=+6**
- **T = min(85+6, 100) = 91**（S 级）
- 那个"+6"直接加在顶层的 85 上，**没有回头去改"战略维"的 4 分**——这就是"不参与加权、但参与总分"的准确含义。

**总评 = min(B + F, 100)**（软封顶，见 §1.5 归一性归位）。定级：S≥85 / A 70–84 / B 60–69 / C<60。

> 量纲说明：基线分 B 已归一化到 0–100；放大器 F 是 0–15 的裸加分。`min(·,100)` 把叠加上限锁回 100，恢复 0–100 基准，使定级阈值（按 0–100 设计）严格自洽。当前 13 事件 B+F 最大为 91，未触发封顶，封顶仅作为制度约束存在。

### 1.3 关于"市场验证"维度的特别说明（度与时机）

本维度**不是机械衡量"是否已被市场验证"**，而是判断事件当前处于验证周期的哪一段：

- **拐点段（影响最大）**：事件爆发扩散初期，伴随"模糊/朦胧感 + 小范围初步市场验证"带来的消息发酵，形成趋势拐点——此时扩散速度与影响力最大。
- **衰竭段（影响最小）**：一旦**完全**被市场验证（靴子落地），利好利空即出尽，影响力进入衰竭期，只能为下一波类似事件做铺垫、沉淀为社会记忆储备。
- 因此：打分时应结合"事件处于验证周期哪个阶段"，**验证滞后于事件影响本身**；"已完全验证"反而对应较低的当期影响力。该维度权重已降至 5%，仅作边际校准。

### 1.5 归一性归位与封顶规则（审核处理）

为消除"百分制基线 + 裸加分放大器"的量纲不齐（原总评可超 100，导致定级阈值失效），归一化处理如下：

1. **权重和归一校验**：7 维权重（24+20+17+15+12+7+5）= **100%** ✓。任何版本改动后须先校验"权重和 = 100%"，否则不可定级。
2. **基线分 B 归一**：B = [Σ(维度分 × 权重)] ÷ 5，全 5 分 = 100、全 0 分 = 0，故 B ∈ [0,100]。
3. **放大器 F 封顶**：F = T1 + T2 + T3（命中者相加），**F ≤ 15**（硬性上限，防止多触发器无限堆叠）。
4. **总评软封顶**：`T = min(B + F, 100)`。把叠加上限锁回 0–100，恢复归一基准；定级阈值（S≥85/A70–84/B60–69/C<60）严格适用。
5. **可复现换算（审计用）**：任意放大器分可反推成"等价维度分"——`F 分 ÷ 20 = 等价 0–5 分`（如 +8 → 0.4 × 20 分 = 等价于在某 100 分基准上加 8 分）。审计时若发现某事件 B+F 越 100，须记录"已封顶至 100"并保留原始 B+F 留痕。
6. **一致性铁律**：基线权重与放大器一旦确定，**整批事件必须同用一套参数**，不得逐事件换权重；任何参数变更须走版本号（v3 → v4）并全量重排。

### 1.6 触发器等价分速查（F 分 ↔ 0–5 维度当量，换算系数 F÷20）

> **口径说明（避免与榜单表混淆）**：榜单表"放大器"是**直接加到 0–100 基线**的叠加分（如 GPT-6 基线 85 + 放大器 +6 = 总评 91），与 §1.5-4 的 `T = min(B + F, 100)` 一致，即"放大器 +N"就是"加 N 分"。本表仅作**审计换算**——把 F 折成"0–5 维度当量"，系数取 `F ÷ 20`（F=+8 → 0.40；F=+15 → 0.75，均落在 0–5 区间内，可对齐任一维度分口径）。它**不改变**榜单表的加法口径，最终总评仍受 §1.5 软封顶约束、不越 100。

| F   | 折 0–5 维度当量（F÷20） | 说明                         |
| --- | ---------------- | -------------------------- |
| +3  | 0.15             | T2 下限                      |
| +5  | 0.25             | T1 下限 / pacing 共识类         |
| +6  | 0.30             | T2 上限 / T1 中位              |
| +8  | 0.40             | T1 上限 / T3 中位              |
| +10 | 0.50             | T3 上限（政策尾部最高）              |
| +15 | 0.75             | 多触发器叠加理论峰值（须先过 §1.5 封顶再定级） |

### 6.2 独立复核与校对闭环（SOP，供下版本复用）
1. **先校权重、再定级**：任何版本改动 → 校验"权重和 = 100%" → 否则禁止定级（§1.5-1）。
2. **独立重算**：基线分 B 由维度分独立加权，不沿用旧值；逐事件填 §6.1 表。
3. **放大器留痕**：每个命中触发器须写清"触发事件 + 归属维度标签 + 加分"，F 求和后校验 ≤15（§1.5-3）。
4. **封顶校验**：对每个事件算 B+F，若 >100 则记录"已封顶至 100"并保留原始 B+F（§1.5-4、5）。
5. **铁律一致性**：整批事件同用一套权重与放大器参数；参数变更必须升版本号（v3→v4）并全量重排，禁止逐事件换参（§1.5-6）。
6. **承重数字二核**：每条 S/A 级事件承重数字须 ≥2 独立来源；单源（如 #8、#13）标"待再核"，不进入 S 级排序结论。
7. **变更留痕**：本机制自 v3 起生效；v3 关键审核发现 = "原设计 B+F 可超 100、定级阈值失效"已用软封顶 `min(B+F,100)` 修复，数值因当前最大 91 而保持不变。

### 6.3 已知未决项
- 触发器 F 的取值（+5~+8 等）为**主观离散档位**，非客观公式；跨版本比较时须固定同一档位定义，否则不可比。
- "市场验证"维度 5% 已降级为边际项，但 §1.3 的"度与时机"原则仍需在打分时结合事件所处验证周期手动判断——这是该维度无法纯公式化的根因，留待未来引入"验证周期阶段"子标签后量化。
